# Road Accident Severity Analysis Using Statistical Modelling in R

## Project Overview
This group project was completed as part of the Statistical Modelling module at the Sri Lanka Institute of Information Technology (SLIIT).

The project investigates factors associated with road accident severity and explores how statistical modelling can support road safety decision-making.

## Objectives
- Explore road accident data and identify relevant patterns.
- Investigate associations between accident characteristics and severity.
- Apply statistical modelling techniques.
- Evaluate model performance under class imbalance.
- Discuss the potential use and limitations of statistical models for road safety.

## Methods and Techniques
- Exploratory Data Analysis
- Statistical Hypothesis Testing
- Chi-square Tests, ANOVA and t-tests
- Principal Component Analysis (PCA)
- Weighted Ordinal Logistic Regression
- Weighted LASSO
- Class Imbalance Evaluation
